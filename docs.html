安装与使用

INSTALL · CONNECT · TROUBLESHOOT

三件事：先装电脑端，再让手机连上，剩下都是在用。

01电脑端

macOSAPPLE 芯片

  1. 下载 Aster-x.y.z-arm64.dmg，双击打开。
  2. 把 Aster 拖进「应用程序」。
  3. 第一次打开若被系统拦住：在「系统设置 → 隐私与安全性」里点「仍要打开」。
  4. 启动后会看到六位码和一个二维码——下一步要用。

Windows

  1. 下载 Aster Setup x.y.z.exe，双击安装。
  2. 首次运行若出现 SmartScreen 提示，点「更多信息 → 仍要运行」。
  3. 装完同样会出现六位码。

电脑端是唯一存数据的地方：对话、记忆、情绪、任务都在本机。换机器时用「设置 → 导出记忆」打包带走。

02手机端

手机不跑模型，只是连过去的一扇窗。连之前，电脑端要开着。

  1. 手机和电脑连同一个 Wi-Fi。不在同一个网时，需要能访问到电脑（例如私有网络或内网穿透）。
  2. 打开手机上的 Aster，扫电脑上的二维码；或点「输入六位码」，把电脑上的六位数字填进去。
  3. 连上后会自动跳进对话页；下次打开会自动重连。

连不上时按顺序查

  1. 电脑端是不是开着、有没有被休眠。
  2. 两端是不是同一个网络。
  3. 六位码有没有过期（十分钟有效，重新生成一个）。
  4. 电脑防火墙是否拦了 8777 端口。

03第一次用

  1. 在「设置 → 角色」里改名字：不叫 Aster 也行。
  2. 在「设置 → 模型」里选一个模型（本机的，或你自己有密钥的云端）。
  3. 回对话页，说一句话试试。它会记住，下次不用再说。

04数据在哪

  • macOS：~/Library/Application Support/Aster/memory
  • Windows：%APPDATA%\Aster\memory
  • 删掉这个目录，等于彻底清除，没有云端备份。
  • 只想删某一条记忆：在记忆页逐条忘掉。

05常见问题

Aster 会联网吗？

只有你让它查资料、或你选的是云端模型时才会。对话内容不经过我们的服务器。

换电脑要不要重买？

不用。用「导出记忆」打包，在新机器上导入即可，模型和钥匙自己配。

它主动说话太频繁 / 太少

在「设置 → 通知」里调；主动的频率跟着关系走，越熟越密。

能不能不给它文件权限

能。设置里有三档权限，最窄的一档只能读；删除、外发、花钱永远要先问你。
