产品说明

WHAT IT IS · HOW TO START · WHAT IT DOES · WHERE DATA LIVES

Aster 是一个装在自己电脑上的陪伴体。它记得你说过的话，能替你在本机动手做事，手机是它的远程窗口。数据不经过我们的服务器，也不需要注册账号。

01它是什么

与常见的对话产品相比，差别在三处：

  • 记忆存在本机。对话、事实、情绪与任务都落在你自己电脑上的一个目录里；卸载即清除，没有云端副本。
  • 它会长。初装时一无所知；此后每一次交谈都会留下一点东西——作息、口味、交付的节点、你说过的话。
  • 它能动手。读文件、写文档、整理目录、运行命令、查资料，都在本机执行；每一步留痕，可回看，可撤回。

02上手

电脑端唯一存数据处

  1. 下载对应平台的安装包并安装；首次打开若被系统拦截，按提示选择「仍要打开」或「仍要运行」。
  2. 启动后界面会给出六位码与二维码，供手机连接使用。
  3. 在「设置 → 模型」中选定模型：本机模型，或填入自己持有的云端密钥。

手机端

  1. 手机与电脑处于同一网络；不在同一网络时，需能访问到电脑。
  2. 扫码，或输入电脑上的六位码。
  3. 连上后进入对话页；再次打开会自动重连。

手机默认不运行模型，是连回电脑的一扇窗。连不上时仍可查看最近的对话，也可先留一句，待连上后自动同步。

另有一个可选项：在手机上填入自己的云端密钥（默认关闭）。开启后，电脑不可达时可先由云端代答，该回复会标注为「手机上的临时版」——它只带少量近期记忆，与电脑上的它并不完全相同。连回电脑后，这段对话会一并带回。密钥只存在手机本地；开启时的请求直接发往模型提供方，不经过我们的服务器。

04记忆与数据

  • 存放位置。macOS 为 ~/Library/Application Support/Aster/memory；Windows 为 %APPDATA%\Aster\memory。
  • 会淡忘。旧事随时间变淡，被提起时复现；不会悄无声息地消失，也不会硬性删除。
  • 可带走。「设置 → 导出记忆」打包迁移，换一台机器后继续使用。
  • 可清除。删掉该目录即为彻底清除；只删某一条，则在记忆页逐条忘掉。

05权限

权限分三档，最窄一档只能读取。以下三类动作在任何档位下都必须先经你确认：

  • 删除——不可逆，必先询问。
  • 对外发送——消息、邮件等一旦发出无法收回。
  • 花钱——生图、调用付费模型等产生费用的动作。

其余在本机范围内的读写与执行，按你在设置中选定的档位放行，并在事后留下记录。

06常见问题

会联网吗？

仅在你让它查资料、你选用云端模型，或你在手机上开启了自己的密钥时。开启手机密钥后，请求从手机直连模型提供方；除此之外，对话内容不经过我们的服务器。

换电脑是否需要重新付费？

不需要。用「导出记忆」打包，在新机器上导入即可；模型与密钥自行配置。

它主动说话过于频繁或过于稀少？

在「设置 → 通知」中调整。主动的频率随关系而变化，相处越久越密。

能否不给它文件权限？

可以。最窄一档只能读取；删除、外发与花钱仍会逐次询问。

手机连不上怎么办？

依次核对：电脑是否仍在运行、两端是否处于同一网络、六位码是否过期（十分钟有效）、防火墙是否拦截了 8777 端口。
