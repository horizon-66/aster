说明

安装、配对、迁移，以及出问题时先看哪一步。

安装

macOS

  1. 下载 .dmg，双击挂载，把 Aster 拖进「应用程序」
  2. 第一次打开若被系统拦下：右键 → 打开，确认一次即可
  3. 启动后引擎自动运行；界面右上角显示「本地」即已就绪
安装包约 530 MB，内含 Python 运行环境，无需另装任何依赖。

Windows

  1. 下载 .exe，按提示安装
  2. 首次运行如遇安全提示，选择「仍要运行」
  3. 模型与记忆同样保存在本机

手机

  1. 在电脑上打开「设置 → 手机连接」，取得二维码或令牌
  2. 手机与电脑处于同一网络时扫码即可配对；不便安装时，直接用浏览器打开该地址
  3. 人在外面时，电脑需开着；手机连 aster.asternest.net 即可（固定地址，由 Cloudflare 隧道转发回本机），无需同一网络

鸿蒙（HarmonyOS）

  1. 下载 .hap，在手机上用文件管理器打开
  2. 系统提示时允许「安装未知来源应用」；当前为调试签名包
  3. 首次打开会先出现说明页，按提示扫码配对即可

模型

对话默认由本机模型完成。设置里可选本机已安装的模型；7B 约需 5 GB 内存，14B 约需 9 GB。

可以另外接入多家云端模型，按角色分工：议事时分别提出方案与审阅，编码时分担编写与复核。每家各自填写密钥，密钥保存在系统钥匙串。

记忆

记忆由几部分组成：条目库（mem.db）、事实表（名字、住处、家人与偏好）、画像、以及当下的情绪状态。全部保存在本机。

旧记忆会随时间变淡：先模糊，再算忘掉；被重新提起会加固。身份、关系与忌讳的衰减很慢。

导出与迁移

  • 桌面：设置 → 记忆包 → 导出 / 导入（zip）
  • 对话记录：对话页右上「导出」，写成文本文件放在 memory/exports/
  • 手机记下的内容：恢复连接后自动上传，能识别时间的会整理成日程

数据与隐私

  • 对话默认走本机模型，不上传
  • 使用云端时，请求直连你选择的服务商，使用你自己的密钥；我们不设中转服务器
  • 费用按各家实际用量计，本地模型不计费
  • 一条记忆约 100–200 字节，十万条约 20 MB
  • 卸载应用不会删除记忆；记忆位于「应用支持」目录，需要时请自行导出或删除

出问题先看这几步

  1. 设置 → 关于 → 运行自检：逐项检查引擎、密钥、模型、记忆库、身份、人格、关系与声音服务
  2. 若对话提示「引擎没应声」：退出应用后重新打开；仍不行，检查 ~/Library/Application Support/Aster/memory/ 是否可写
  3. 答非所问：先确认设置里当前使用的模型是否符合预期
