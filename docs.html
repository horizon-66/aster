说明

装、配、带上记忆，以及出问题时先看哪。

安装

macOS

  1. 下载 .pkg，双击安装
  2. 第一次打开如果被 Gatekeeper 拦下：右键 → 打开
  3. 打开后会自己起引擎，界面右下角显示「本地」就绪
安装包约 630 MB，里面带着 Python 运行时；不需要你另装环境。

手机

  1. 手机浏览器打开 /app/
  2. Safari 分享 → 添加到主屏幕；Chrome → 安装应用
  3. 设置里填 Base URL、模型名、API Key（手机上不跑模型）

模型

桌面版默认连本机的 Ollama。设置里「本地大脑」可以一键拉取；7B 约 5 GB 内存，14B 约 9 GB。

手机版不跑模型，调用你在设置里填的 OpenAI 兼容接口。

记忆

记忆分三样：条目库（mem.db）、摘要快照（briefs.json）、当下状态（bus.json）。都在本机，随时可导出。

导出与导入

  • 桌面：设置 → 记忆包 → 导出 / 导入（zip）
  • 手机：设置 → 记忆包 → 导出 / 导入（json）
  • 手机 → 桌面：同一 WiFi，填电脑地址，点同步；记录和账目会进桌面工作台

数据与隐私

  • 对话默认走本机模型，不上传
  • 用云端时，请求直连你选的服务商，用你自己的 key；没有中转服务器
  • 一条记忆约 100–200 字节，十万条约 20 MB
  • 删掉应用不会删掉记忆；记忆在「应用支持」目录里，需要手动导出或删除

出问题先看这几步

  1. 设置 → 自检：它会检查引擎、人格、记忆条数、情绪，并给出人话结论
  2. 「引擎没开」：退出应用再开；仍不行看 ~/Library/Application Support/Aster/memory/ 是否可写
  3. 答非所问：先看设置里当前模型是不是你要的那个
